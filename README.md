# Match2Date

Seu assistente de conversas para apps de namoro, Instagram e WhatsApp, no Windows.

Aqui ficam só os instaladores e as novidades de cada versão. O programa se atualiza sozinho: quando sai uma versão
nova, ele avisa em **Ajustes** e instala com um toque, sem perder suas conversas nem seus ajustes.

## Como instalar

1. Em **Releases**, à direita, abra a versão mais recente e baixe o arquivo `Match2Date-<versão>.exe`.
2. Abra o arquivo baixado. A instalação é só para a sua conta do Windows e não pede senha de administrador.
3. O Match2Date abre no fim. Na primeira vez, ative a licença que você recebeu (começa com `M2D`).

Precisa de Windows 10 ou 11 de 64 bits e do Google Chrome instalado.

## Novidades

O que mudou em cada versão está no arquivo [CHANGELOG.md](CHANGELOG.md) e na página de cada versão em **Releases**.

## Seus dados

As conversas, a agenda e os ajustes ficam só no seu computador, protegidos com criptografia. Atualizar ou
desinstalar o programa não apaga nada disso.
